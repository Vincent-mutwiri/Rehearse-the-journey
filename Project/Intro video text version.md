What is the toolkit: text version of the intro video

AI for Accessibility Collective. Video length 4 minutes 20 seconds. Text version written 30 October 2026\.

About this text version

This is the whole video in text, for reading with a screen reader. It follows the video from start to finish, in five scenes. Each scene starts with its time in the video and a short description of what is on screen. Then come the words as they are heard, each line starting with who is speaking. "On screen" lines describe text and pictures that the spoken words do not cover.

One narrator speaks throughout. The video also uses real demo recordings of the toolkit, with the real speech heard during those demos, and two synthesized voice clips made only for this video. Each voice is identified where it speaks. The headset and phone views in scene 4 are simulated: working web pages, not real devices.

On screen: made-here slides on a warm cream background, with dark green text, a serif typeface for headlines and white cards with soft shadows.

On screen: a headline: "Many websites and apps still put barriers in front of disabled people."

Narrator: Many websites and apps still put barriers in front of disabled people. What's new now is agentic AI.

On screen: the headline changes to "What's new now is agentic AI." Two cards appear side by side. The first, headed "An agent uses a website", shows a simple web page with a button reading "Next step", and the words "Together with you: an AI agent can use a website with you." The second, headed "A coding agent builds an app", shows the request "Build me an app with large buttons", and the words "From plain words: a description becomes a working app."

Narrator: An AI agent can navigate a website together with you, and a coding agent can build an app from a description just using plain words.

On screen: "One day very soon, people may be able to build what they need for themselves."

Narrator: So, one day very soon, people may be able to build what they need for themselves. We started more simply, though, building code components that developers can pick up and use today.

On screen: "We started more simply: code components developers can pick up and use today."

On screen: a new headline, "Three agents work together with the person", and a row of four cards joined by arrows, appearing one at a time as each is named. The first card, dark green, reads "You: say what you need." Then "Ability profile agent: keeps a record of what you've asked for." Then "Adapter agent: changes a page or an app to match." Then "Verification agent: checks the result against your request." A line runs from the last card back to the first, marked "Back to you: the result comes back to you."

Narrator: Our toolkit has three agents that work together with the person. First, the Ability profile keeps a record of what you've asked for. Next, the Adapter agent changes a page or an app to match. And finally, the Verification agent checks the result against what you've asked for, and then it comes back to you.
