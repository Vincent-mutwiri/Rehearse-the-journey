**Decision today:** Pivot the conversation-practice core to **Pipecat** for the Nov 7 demo. Hybrid architecture:
- Pipecat (Python) owns the spoken role-play (SmallWebRTC transport, Gemini Live s2s).
- React (TS, Vite, from `pipecat init`) owns the journey state, approval gate, AbilityModel prefs, toolkit DOM adapters.
- Typed role-play input = guaranteed alternative in React; demo degrades gracefully if voice fails.

**Deployment & cost reality (added to §7 of the sprint plan):**
- Nov 7 demo: run locally on the laptop — $0, no cloud.
- Vercel split: React frontend → Vercel (static, free). Pipecat bot → NOT Vercel (long-running Python voice process; Vercel serverless kills it in ~10–300s). Fundamental mismatch, not a config tweak.
- v1.1: bot on Pipecat Cloud `agent-1x` @ $0.01/min active; Daily WebRTC free for 1:1; inference BYOK (hub Gemini key). No published free hosting tier, but $0 entry + no monthly minimum; `max-agents` = spend cap. Self-host (Fly.io/Modal/Render/Railway) is the open-infra alternative.
- Pipecat framework itself = BSD-2, free to self-host.
